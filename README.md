# Personal Site

Minimal personal site for writing and experiments.

The site is built from Markdown content using a small TypeScript build script and static HTML/CSS output.

## Structure

```text
content/
  writing/
  experiments/
public/
  assets/
src/
  build.ts
  config.ts
  content.ts
  routes.ts
  templates/
  styles/
dist/
```

## Commands

```sh
npm run build
npm run dev
```
